## 项目简介
本项目严格根据《学生实践指南六》第七部分分步实现双库数据看板：
1. **异步数据流**：使用原生 `fetch` 与 `async/await` 异步加载本地 JSON 数据，具备“加载中”、“成功”、“加载失败”与“暂无数据”四状态拦截。
2. **统计卡片**：使用 jQuery 动态生成图书品类借阅累计卡片，并绑定事件委托实现点击高亮交互。
3. **ECharts 柱状图**：渲染 12 个月 6 大品类借阅量柱状图，支持悬浮 Tooltip 与图例切换。
4. **Chart.js 折线图**：渲染各品类借阅趋势折线图，实现防重复初始化与窗口 Resize 响应式重绘。
